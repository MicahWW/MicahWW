## About my website

If you're reading this from my GitHub profile page you might not realize that the source code for [micahww.com](https://micahww.com) is located in my [MicahWW repository](https://github.com/MicahWW/MicahWW), so head over there to take a look at the code. Once there you will see a <ins>***NextJS***</ins> project with the main content under the [/src directory](https://github.com/MicahWW/MicahWW/tree/main/src). You will also see via the workflow file [Azure-Build-and-Push.yml](/.github/workflows/Azure-Build-and-Push.yml) that the code is compiled and then sent to Azure to be hosted in an [<ins>***Azure App Service***</ins>](https://azure.microsoft.com/en-us/products/app-service).
